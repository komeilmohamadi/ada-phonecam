# Trusted phone and full camera profile

The studio remembers one browser on one phone per server installation when Remember this phone is enabled for QR pairing. The browser keeps a random credential in local storage; the server stores only a SHA-256 digest in runtime/trusted-phone.json. Ordinary refreshes and server restarts do not revoke this credential. Open the same HTTPS LAN address (including its port), or its /phone path, on the phone. The studio must be running. Start Camera remains a deliberate action; no camera is activated by authentication alone.

Use Forget trusted phone on the studio to revoke trust and disconnect the phone. Scan a new QR code after clearing browser data, changing the server origin, or revoking trust. A private browsing window may not persist credentials. A new remembered phone replaces the previous one. Do not share the browser or trust credential.

After applying quality and camera adjustments in the studio, choose Save Profile. The phone persists one complete capture profile in its browser storage. The three existing quality-only presets are separate. Load Profile restarts capture using the saved device, requested quality, orientation, explicit capture constraints and supported reported image controls. On the phone, Use saved camera profile is selected when a saved profile exists. Uncheck it to start normally. Saved torch state is restored only when explicitly starting with the profile or loading it while capture is active. A saved microphone state never enables microphone capture without the phone's Include microphone consent checkbox. Unsupported or changed controls are reported; an unavailable saved camera or unsupported codec can require starting without the profile and saving a new one. No profile changes are sent automatically until capture is requested. Studio-only feed transforms and native output are separate settings.

Validate on real Android Chrome: pair, save, refresh the phone, restart the studio and server, reconnect via the same URL, start with the profile, verify actual camera and stream statistics, then revoke and check that the old credential no longer works. Clear browser storage and check that a fresh QR is required.
